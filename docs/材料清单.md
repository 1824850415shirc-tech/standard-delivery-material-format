# 各类文档建议材料清单

材料清单用于引导用户提供已有依据，不表示每个项目都必须具备全部文件。缺失材料记录为待补充项，不据此编造内容。

## 一、项目前期

### 1. 项目章程

优先提供：

- 立项申请、任务书、合同、招标文件或会议决议；
- 项目背景、业务目标、范围边界和预期成果；
- 项目干系人、组织分工、决策和汇报机制；
- 预算、计划周期、关键里程碑和资源约束；
- 已知风险、前提假设和成功标准。

### 2. 调研方案

优先提供：

- 调研任务、决策背景和待回答的问题；
- 已有业务、系统、组织和数据范围说明；
- 计划访谈的角色、部门或外部对象；
- 可用资料、统计数据、现场条件和时间窗口；
- 保密、合规、数据使用和成果确认要求。

### 3. 调研报告

优先提供：

- 已确认的调研方案、问题清单和调研范围；
- 访谈纪要、问卷、现场记录或会议材料；
- 现状流程、系统清单、统计数据和问题记录；
- 备选方案资料、同类案例和验证结果；
- 适用的制度、标准、预算和时间约束。

### 4. 实施方案

优先提供：

- 合同、任务书、项目章程和已确认范围；
- 需求、调研结论、总体设计或技术方案；
- 现有环境、网络、软硬件和资源清单；
- 计划周期、里程碑、人员分工和现场窗口；
- 数据迁移、部署切换、回退、验收和安全要求。

## 二、项目过程

### 1. 需求规格说明书

优先提供：

- 合同、招标文件、任务书或项目范围说明；
- 业务流程、调研记录、访谈纪要和现状材料；
- 既有系统说明、数据字典和接口资料；
- 验收要求、合规制度和性能目标；
- 原型、页面草图或历史需求文档。

### 2. 详细设计说明书

优先提供：

- 已确认的需求规格说明书或技术规格说明书；
- 源代码、代码仓库目录或关键模块代码；
- 总体设计、架构图、部署图和组件说明；
- 数据库设计、数据字典、接口文档和消息定义；
- 运行环境、配置清单、安全规范和验收标准。

### 3. 数据库设计

优先提供：

- 需求规格说明书、详细设计和业务数据模型；
- 现有数据库结构、DDL、数据字典和 ER 图；
- 数据量、增长率、查询场景和性能目标；
- 数据安全、审计、保留、归档和合规要求；
- 备份恢复、迁移、版本发布和回退要求。

### 4. 测试方案与用例

优先提供：

- 已确认的需求、设计、接口和验收标准；
- 测试范围、版本计划、质量目标和缺陷规则；
- 测试环境、账号权限、测试工具和数据条件；
- 历史缺陷、高风险模块和生产问题记录；
- 性能、安全、兼容性等专项测试要求。

### 5. 测试报告

优先提供：

- 已确认的测试方案、测试用例和版本基线；
- 用例执行记录、测试日志和测试证据；
- 缺陷清单、修复验证记录和遗留问题；
- 性能、安全、兼容性等专项测试结果；
- 需求覆盖统计、通过口径和测试结论依据。

### 6. 运维手册

优先提供：

- 系统架构、部署图、环境和配置清单；
- 安装部署文档、启停命令和健康检查方式；
- 监控指标、告警规则、日志路径和巡检记录；
- 备份恢复、发布回滚和应急预案；
- 历史故障记录、服务级别要求和安全制度。

### 7. 系统接口文档

优先提供：

- 系统架构、集成关系、调用方向和网络边界；
- OpenAPI、Swagger、Postman、消息或文件接口定义；
- 请求响应样例、数据字典、错误码和业务规则；
- 认证授权、签名、加密、幂等、超时和重试约定；
- 联调记录、版本兼容、监控指标和服务级别要求。

### 8. 操作手册

优先提供：

- 功能清单、用户角色和权限说明；
- 测试环境页面、脱敏截图、原型或演示材料；
- 业务流程、字段规则、状态流转和操作限制；
- 已有用户手册、培训材料和常见问题；
- 验收用例、错误提示和支持流程。

## 三、项目收尾

### 1. 验收报告

优先提供：

- 合同、任务书、需求基线、变更确认和验收标准；
- 项目交付物清单、版本信息和提交记录；
- 测试报告、试运行报告、培训和移交记录；
- 验收用例、检查记录、问题整改和关闭证据；
- 遗留事项、责任分工和后续完成计划。

### 2. 试运行报告

优先提供：

- 试运行方案、上线确认、运行范围和起止时间；
- 实际部署版本、环境配置和变更记录；
- 业务使用量、性能指标、监控和可用性数据；
- 告警、故障、用户反馈和问题处理记录；
- 备份恢复、运维值守、培训移交和改进计划。

## 四、材料处理原则

- 优先使用版本明确、已确认且与当前交付范围一致的材料。
- 分别核对合同约束、技术实现和运行现状，不能相互替代。
- 源代码反映实现，但不自动证明业务验收口径。
- 合同反映约定，但不自动证明系统已经实现。
- 历史文档可能过期，标注版本并与当前材料交叉核对。
